# Revisions

Logiciel de révision (Windows).

Installation : télécharger `Revisions-Setup.exe` dans la dernière version (Releases), puis le lancer. Si Windows affiche « Windows a protégé votre ordinateur », cliquer sur « Informations complémentaires » puis « Exécuter quand même ».

Les mises à jour s'installent ensuite toutes seules au démarrage.
